This is the "lock-free" variant: the subject is required to DRIFT across the frame, possibly
running off the frame edge, and the background is required to parallax. It is what produced
the measured contrast recorded in SKILL.md hard rule 10 (same subject, same model, same
angle: locked framing -> translation / area_cv 1.3% / total change 2.225, versus this variant
-> pose-change / 5.1% / 3.315).

It was accepted on g1.jpg, but the user has since decided that the DEFAULT behaviour is the
opposite: THE SUBJECT STAYS IN THE MIDDLE OF THE FRAME and the travelling is done by the
BACKGROUND (SKILL.md hard rule 17). The default template has been rewritten accordingly.

Only fall back to this file when the subject is so large that holding it centred would make
the sheet look dead - and say so to the user before spending points. It also lacks the
SUBJECT section (hard rule 16) and the 180-style drift wording, so if you do use it, add the
SUBJECT paragraph from the default template first.
